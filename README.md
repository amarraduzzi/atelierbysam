# L'Atelier by Sam
Statische website (HTML/CSS/JS), geen build nodig. Werkt direct op Cloudflare Pages of GitHub Pages.

- Kleuren: bovenaan `css/style.css` (:root)
- WhatsApp-nummer: bovenaan `js/main.js`
- Foto's: zet in `assets/photos/` en vervang de `.ph`-blokken in `index.html` (zie commentaar bij de hero)
- Kaart, adres, uren, telefoon: in `index.html`
